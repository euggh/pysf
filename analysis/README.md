# Анализ данных csv файла

### Описание

Данная программа предназначена для анализа данных загруженных из csv файла. Она обладает следующими возможностями:
- Показывает содержимое файла в виде таблицы с возможностью выбора столбцов
- Проведение статистического анализа (среднее,медиана,отклонение)
- Построение линейного графика и диаграммы рассеяния

### Установка зависимостей

Для работы требуется установить следующие бибилиотеки python  
pip install streamlit  
pip install pandas  
pip install plotly  

### Запуск

Для запуска приложения наберите:

streamlit run analysis.py
